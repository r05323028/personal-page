## Project Overview

Developed a task management application focused on team collaboration. The app features drag-and-drop task organization, real-time updates, and customizable workspaces.

## Key Features

- Drag-and-drop task management
- Real-time collaboration
- Team workspaces
- Custom labels and filters
- Activity timeline

## Technologies Used

- Vue.js 3 with Composition API
- Firebase for real-time database
- Tailwind CSS for styling
- Vuex for state management
